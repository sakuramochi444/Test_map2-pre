## 現状
- Display1が管理画面、Display2~5がプレイ画面
- Enemyは出現位置固定、ランダムウォーク
- 目の前にPlayerがいた場合、追跡
- Enemyと接触後、戦闘シーンへ遷移
- Chestは固定位置に出現、接触後回収
- 階層移動可(計5階層)
- ステータスは体力・攻撃力・防御力・速度の四つ
- 攻撃時に攻撃力ー防御力の値が体力から減算
- 最低保証で攻撃は確定1ダメージ
- 速度は、Playerの速度÷Enemyの速度の値分Playerが行動した後、Enemyが行動
- 戦闘シーンでは通路方面に1~4体出現
- Enemyは4種類（スライム・スケルトン・ゴーレム・ゴースト）
- 武器は剣（物理）・杖（特殊）の2種類
- スライム・スケルトンは物理が、ゴーレム・ゴーストは特殊が弱点
- 弱点以外は攻撃が通らない
- 杖の効果は強化・攻撃・回復
- 強化は次の杖の攻撃が3倍
- 回復は戦闘一回につき一度きり
- 画面左上にミニマップ
- ミニマップの向きは絶対的な方向じゃなくてPlayerが向いてる方向が上
- API通信の追加
- マイコンを通して加速度センサを検知（剣の振り）
